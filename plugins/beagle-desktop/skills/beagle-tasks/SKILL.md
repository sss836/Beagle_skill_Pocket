# 比格直接开工

使用插件提供的 `beagle_*` 工具连接用户自己的本机 Codex。模型与工具能做什么，以该执行环境实际提供的能力为准。

提交前读取 `beagle_status`，确认连接和工作文件夹。没有文件夹时，请用户选择；只把用户明确指定的目录交给 `beagle_configure_workspace`。需要专门技能时用 `beagle_list_skills` 查找真实 ID；不要把缓存存在当成外部服务已经连接。

用户要求选择模型时，调用 `beagle_list_models`，使用返回的真实 `model` 标识提交。未指定时省略模型参数，沿用当前 Codex 设置；不要自行替用户换模型。模型参数控制本次任务主 Agent，子 Agent 能否单独指定模型以宿主工具实际能力为准。

用户已明确交代执行目标时，把目标、约束、附件路径和交付要求传入 `beagle_submit_task`。保留返回的任务 ID。重复查询进度不得重新提交同一任务。收到提交成功只说明任务进入队列，不等于已经完成。

使用 `beagle_get_task` 读取真实状态；需要看历史时使用 `beagle_list_tasks`。只报告返回的进度，不编造百分比。出现等待用户确认或补充信息时，展示任务链接和请求内容，由用户在比格任务看板中答复，不替用户批准权限。

任务状态为 `completed` 后读取最终答复和成果路径；`failed`、`cancelled`、`interrupted` 均不能报告成功。用户明确要求停止时才调用 `beagle_cancel_task`，并说明已写入的文件不会自动撤销。

如果本轮本身是比格派发的执行任务，直接使用当前环境工具完成工作，不通过本插件递归提交。仅询问用法、比较路线或只查状态时，不创建新任务。
